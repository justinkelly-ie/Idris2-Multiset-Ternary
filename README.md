# Idris2-Multiset-Ternary

[![Idris 2 Verification](https://img.shields.io/badge/Idris_2-0.8.0-blue.svg)](https://www.idris-lang.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**Layer 2c Ternary Narayana Multiset Transformations & Tri-State Logic**

`Idris2-Multiset-Ternary` formalizes ternary state transitions and Narayana triangle combinatorics over discrete multiset bases:

- **`Linear.NarayState`**: Narayana state transformation operators mapping tri-state color channels.
- **`Logic.TernaryLogic`**: Discrete ternary logic classifiers ($0, 1, 2$) without continuous approximations.
- **`Reflect.NarayElab`**: Compile-time `%macro` reflection proof tactics for ternary closure.

## 🚀 Building & Installing

```bash
idris2 --build Idris2-Multiset-Ternary.ipkg
idris2 --install Idris2-Multiset-Ternary.ipkg
```
